# 창고 도면 로컬 분석 엔진

외부 AI/OCR 연결 없이 PDF·이미지에서 **검토가 필요한 기하학 후보**를 추출한다. 실사 사진을 평면도로 복원하는 모델이 아니며, 임의 템플릿을 분석 결과로 반환하지 않는다.

## 설치 / 실행

개발 환경의 프로젝트 루트에서:

```sh
python3 -m venv backend/tools/plan-recognition/.venv
backend/tools/plan-recognition/.venv/bin/pip install -r backend/tools/plan-recognition/requirements.txt
```

Python 3.9 이상과 해당 OS용 PDFium/OpenCV wheel이 필요하다. 릴리스 publish에는 `plan-recognition/recognize.py`와 `requirements.txt`가 포함된다. 운영 환경에서는 같은 디렉터리에 venv를 설치하거나 `PlanImport__EngineDirectory`, `PlanImport__PythonPath`를 서버 환경 변수로 지정한다. .NET publish만으로 Python 의존성을 설치하지 않는다. 런타임 부재는 분석 실패로 표시한다.

## 실제 처리

- PDFium: 선택한 PDF 페이지를 최대 긴 변 1800px, 최대 3배로 렌더링. 벡터 PDF와 스캔 PDF 모두 같은 이미지 분석 경로를 사용한다. 폼 렌더링을 끄고 원본 PDF를 브라우저에 제공하지 않는다.
- Pillow: 실제 이미지 포맷·픽셀 수 확인, EXIF 방향 적용, 투명 배경 흰색 합성, 수동 90도 회전, 종횡비 보존. 애니메이션은 거부한다.
- OpenCV: 명확한 종이 사각 경계의 원근과 긴 선의 공통 기울기를 보정한다. 국소 조명을 정규화해 외벽과 내부 사각 윤곽을 구분하고, 외벽 내부의 길쭉한 사각형은 1~2개여도 랙 후보로 제안한다. 사각형 닫힘 보정은 랙 검출에만 사용하며, 외벽의 출입구 크기 틈은 유지한다. 선 지지율이 낮은 문자와 미세 잡음을 제외한다. 기존 반복 배치, 랙 사이 빈 띠, 색상 구역 후보를 유지한다.
- 연속 색조와 조밀한 선 잡음이 함께 있는 일반 사진은 자동 추출을 중단한다. 종이의 네 모서리나 밝기 차이가 불명확하면 임의로 자르지 않는다. 작은 기울기만 자동 보정하고, 90도 방향은 EXIF 및 사용자 선택에 따른다.
- 모든 좌표는 이미지 중심 좌표와 크기를 0~1로 정규화한다. 실제 미터 단위나 랙 단수·칸수는 추정하지 않는다. 신뢰도는 규칙의 강도이며 통계적으로 보정된 확률이 아니다.

## 서비스 경계 / 보안

`PlanImportService`가 비동기 프로세스 실행과 좌표 검증을 담당한다. 향후 다른 분석 엔진을 연결해도 이 검증 및 검토 단계를 거쳐야 한다. 현재 외부 네트워크·AI 호출은 없다.

API: `POST /api/tenants/{tenant}/plan-imports` (multipart), `GET /{id}`, `GET /{id}/preview`, `POST /{id}/page`, `POST /{id}/analyze`, `POST /{id}/discard`.

모든 API는 TenantMember + warehouses:create 권한과 파일 소유자를 확인한다. 분석 모델은 RackId/LocationId를 지정할 수 없다. 임시 객체를 기존 TemplateDocument로 변환하고 기존 창고 workspace 통합 저장만 사용한다. 기존 창고에서는 파일 가져오기 UI를 제공하지 않는다. DB 마이그레이션 없음.

최대 파일 20MB, PDF 30페이지, 이미지 4천만 화소, 종횡비 1:4~4:1, 최대 후보 450개. 서버 전체 20개 임시 작업 / 사용자당 3개 / 기업당 시간당 업로드 20회 / 파일당 분석 6회·페이지 렌더 40회. 동시 프로세스 2개, 각 대기·실행 60초 제한 및 시간 초과 프로세스 종료. 제한은 프로세스별이므로 다중 인스턴스 운영 시 공유 쿼터와 격리된 작업 큐가 필요하다.

파일은 `App_Data/PlanImports/<process>/<job>`에 임의 파일명으로 저장하고 디렉터리 접근을 소유자로 제한한다. 원본을 정적 공개하지 않으며 로그에 원본/인식 문자를 기록하지 않는다. 모달 닫기 시 삭제 요청, 요청 도달 실패/탭 종료 시 업로드 후 30분 만료 및 분당 정리. 서버 정상 종료 시 삭제, 비정상 종료 잔여 디렉터리는 재시작 후 만료 정리한다. 안전한 파서 업데이트와 OS 프로세스 격리는 운영자가 유지해야 한다.

## 한계

곡선·문 여닫이 기호·복잡한 CAD 표기·작은 문자·심한 원근 왜곡·12도를 넘는 기울기는 포괄적으로 인식하지 않는다. 축척과 카메라 보정 정보가 없으므로 원근 보정 뒤에도 정확한 물리 치수를 보장하지 않는다. 랙 전체 대신 칸 일부를 잡거나 랙 선을 벽으로 잡을 수 있다. OCR, 의미 기반 구역 분류, 실제 치수 추출, 상용 도면에 대한 보정된 정확도는 제공하지 않는다. 원본 비교와 수동 유형 변경/추가/삭제/배치 수정이 필수다. 랙 이름과 코드는 임시 제안값이며 직접 수정할 수 있다. 단수·칸수를 직접 확인해야 적용할 수 있다. 보정된 이미지에 후보를 겹쳐 보여주며, 낮은 신뢰도는 점선으로 표시한다. 실패 시 원본을 유지하고 직접 편집으로 전환할 수 있다.
